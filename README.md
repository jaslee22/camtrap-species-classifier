# 무인센서 종분류 · 촬영일시 추출기

무인센서(카메라 트랩) 사진·영상에 찍힌 포유류의 종을 자동으로 분류하고 촬영일시를 추출하는 프로그램의 **배포 전용 저장소**입니다.
실행 파일만 올립니다.

## 내려받기

[최신 버전 내려받기](https://github.com/jaslee22/camtrap-species-classifier/releases/latest) 에서 `camtrap_v*.exe` 를 받아 실행합니다.

- 설치가 필요 없습니다. 파일 하나만 실행하면 됩니다. GPU 가 없는 PC 에서도 동작합니다.
- 실행이 차단되면(「액세스가 거부되었습니다」) 바탕화면이나 문서 폴더로 옮겨 실행하세요.
- 사용법은 프로그램의 `도움말 > 사용 설명서`(F1) 에 그림으로 들어 있습니다.

## 업데이트

이미 쓰고 있다면 따로 받을 필요가 없습니다. 프로그램을 켤 때 새 버전이 있으면 알려 주고,
`지금 업데이트` 를 누르면 내려받아 새 버전으로 바뀝니다. `도움말 > 업데이트 확인` 으로 직접 확인할 수도 있습니다.

## 저작권과 사용 조건

- 본 프로그램과 포함된 학습 모델의 저작권은 **국립생태원 자연환경조사팀**에 있습니다.
- 자연환경조사 업무 목적으로만 사용하며, 무단 복제·배포·개작을 금지합니다.
- 자동 판정은 1차 선별 자료입니다. 최종 종 동정은 조사자가 확인해야 합니다.
- 제3자 구성요소 고지는 프로그램의 `도움말 > 저작권·오픈소스 고지` 에 있습니다.
